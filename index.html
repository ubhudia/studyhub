Written practice

Print-ready files

Open a PDF, then print it. For both card files:

  1. Print the whole file double-sided.
  2. Choose flip on the long edge (sometimes called long-edge binding).
  3. Set the size to 100% or actual size, not fit to page.
  4. Check that A1 is behind Q1, then cut along the dashed lines.

New printer? Print one card sheet first (pages 3 and 4 of the long flashcards) and hold it up to the light before printing the rest.
